# Project Summary
This project builds a complete analytics foundation for an e‑commerce business by transforming raw transactional and web‑behavior data into a structured, insight‑driven model. 
Using six core datasets—orders, order items, refunds, products, website sessions, and pageviews, the project designs a tailored star schema and develops clean fact and dimension tables that unify the customer journey from first website visit to purchase and potential refund. 
A full SQL analytics roadmap guides the creation of revenue, product, marketing, funnel, and customer‑behaviour analyses. 
The project also delivers reusable SQL views to support dashboards and ongoing KPI monitoring, enabling clear visibility into traffic quality, conversion performance, product profitability, and refund impact. 
The result is a scalable, end‑to‑end analytics layer that supports decision‑making across marketing, product, finance, and operations.
